后端工程师，4 年经验，现于国内一线大厂负责平台架构与 AI Agent 工程化落地。

日常在做的事情：把分散在各业务系统里的重复能力收敛成统一平台，并让这些平台在高流量、强一致的场景下稳定运行。近两年重心转向 AI Agent 的工程化——如何让 Agent 从 Demo 走到生产。

## 做过的方向

**平台架构**
主导过定时任务调度平台、配置中心、安全服务中心的从 0 到 1 建设，覆盖 60~150+ 子系统的接入与治理。关注的是大规模系统如何平滑演进：存量系统如何零故障迁移、能力如何灰度上线、上下游链路如何保证一致性。

**AI Agent 工程化**
主导智能体用户面中台的架构设计与核心链路落地，涉及 Agent Runtime、分布式有状态沙箱、Checkpoint 持久化与断点续传、Skill/MCP 热加载等能力。也在持续研究多智能体协作模式与 Harness 工程。

## 技术栈

- **语言与框架**：Java（熟练）、Python · Spring Boot / MyBatis / ServiceComb
- **分布式**：分布式锁与事务、分库分表、最终一致性、数据倾斜与一致性哈希
- **存储与中间件**：MySQL（索引 / 事务 / MVCC / 调优）、Redis（集群 / 分布式锁）、Kafka
- **并发**：线程池、悲观与乐观锁、并发容器、生产者–消费者与读写锁模式
- **部署**：Docker、镜像构建、资源调度、多集群发布、滚动升级
- **Agent**：Agent Runtime、Tool Use 编排、MCP 协议、上下文与状态管理

## 这个博客写什么

以工程实践为主，记录三类内容：

- **架构与治理**：平台设计取舍、大规模系统演进、线上问题定位
- **AI Agent**：多智能体架构模式、Agent 工程化、工具链与效率实践
- **算法与基础**：数据结构与算法题解、JVM 与并发基础

写作原则是尽量写清楚「为什么这么做」，而不只是「做了什么」。
