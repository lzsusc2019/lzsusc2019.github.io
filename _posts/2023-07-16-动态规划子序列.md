> **核心思想**：动态规划（Dynamic Programming）在处理子序列问题时，通常需要定义一个状态数组来记录历史信息。
{: .prompt-info }

## 一、最长递增子序列 (LIS)

### 1. 状态转移
`dp[i] = max(dp[j]) + 1`, 其中 `0 <= j < i` 且 `nums[j] < nums[i]`。

### 2. 代码实现
```java
public int lengthOfLIS(int[] nums) {
    int[] dp = new int[nums.length];
    Arrays.fill(dp, 1);
    int res = 1;
    for (int i = 0; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        }
        res = Math.max(res, dp[i]);
    }
    return res;
}
```

## 二、最长公共子序列 (LCS)

> **快速回想**：两个字符串对比，使用二维 `dp[i][j]`。
{: .prompt-tip }

### 1. 状态定义
`dp[i][j]` 表示 `s1` 前 `i` 个字符与 `s2` 前 `j` 个字符的最长公共子序列长度。

### 2. 代码实现
```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // 字符相同，继承左上方值并 +1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 字符不同，取左方或上方最大值
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

---

## 总结
- **一维子序列**：通常 `dp[i]` 表示以 `i` 结尾的解。
- **二维子序列**：通常 `dp[i][j]` 表示两个序列前缀的解。
