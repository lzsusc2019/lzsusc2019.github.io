## 一、并查集 (Union-Find)

> **口诀**：寻根、合并、查连通。解决“两个元素是否在同一集合”的问题。
{: .prompt-tip }

### 1. 核心模板 (带路径压缩)
```java
class UnionFind {
    private int[] parent;
    private int count; // 连通分量个数

    public UnionFind(int n) {
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        this.count = n;
    }

    public int find(int val) {
        if (val == parent[val]) return val;
        return parent[val] = find(parent[val]); // 路径压缩：直连根节点
    }

    public void join(int v, int w) {
        int x = find(v), y = find(w);
        if (x != y) {
            parent[x] = y;
            count--;
        }
    }
}
```

## 二、滑动窗口 (Sliding Window)

> **场景**：连续子数组/子字符串问题。将 $O(n^2)$ 优化为 $O(n)$。
{: .prompt-tip }

### 1. 通用模板
```java
int left = 0, right = 0;
while (right < arr.length) {
    window.add(arr[right]); // 进窗
    right++;
    
    while (windowNeedsShrink) { // 满足特定条件时缩窗
        window.remove(arr[left]); // 出窗
        left++;
    }
}
```

## 三、前缀和 & 差分 (Prefix Sum & Difference)

### 1. 前缀和 (快速求区间和)
- **场景**：原始数组不修改，频繁查询 `sum[i...j]`。
- **公式**：`res = preSum[j+1] - preSum[i]`。

### 2. 差分数组 (区间批量增减)
- **场景**：频繁对 `[left, right]` 区间所有元素加 `val`。
- **操作**：`diff[left] += val; diff[right+1] -= val;`。

## 四、拓扑排序 (Topological Sort)

> **核心**：入度为 0 的节点进队列。用于解决“依赖关系/课程表”问题。
{: .prompt-warning }

### 1. 步骤
1. 统计所有节点的**入度**。
2. 将入度为 0 的节点加入 **Queue**。
3. 弹出节点，将其后继节点的入度减 1；若减为 0 则入队。
4. 若最后处理的节点数 < 总节点数，则说明**有环**。

## 五、BFS 广度优先搜索

- **第一要义**：寻找**无权图**中的**最短路径**。
- **必备工具**：`Queue` (存储层级节点) + `Set/boolean[]` (标记已访问)。

```java
Queue<Node> q = new LinkedList<>();
q.offer(start);
visited.add(start);

while (!q.isEmpty()) {
    Node cur = q.poll();
    for (Node next : cur.neighbors) {
        if (!visited.contains(next)) {
            q.offer(next);
            visited.add(next);
        }
    }
}
```
